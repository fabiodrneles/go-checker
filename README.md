# go-checker

Verificação de saúde de sites e APIs, no terminal ou no CI. A documentação completa (em português e em inglês) chega com a v1.0.0 (spec 008).

```text
go install github.com/fabiodrneles/go-checker@latest
go-checker check https://example.com
```

Códigos de saída: `0` tudo no ar, `1` algum check falhou, `2` erro de uso ou de configuração.
